# راهنمای انتشار سایت RWAB با GitHub Pages

این بسته یک سایت ایستای اطلاعاتی است؛ انتشار آن نیازمند ورود به GitHub از داخل این ابزار نیست و هیچ نشانی زنده‌ای در این فایل ادعا نمی‌شود.

## انتشار برای افراد تازه‌کار
1. فایل `RWAB-site-ready.zip` را روی رایانه دریافت و از حالت فشرده خارج کنید. وارد پوشهٔ استخراج‌شده شوید؛ فایل‌هایی مانند `index.html`، `fa.html`، `styles.css`، `logo.webp` و `favicon.png` باید همان‌جا دیده شوند.
2. در GitHub یک مخزن **عمومی** با نام دقیق `RWAB-site` بسازید. رمز، عبارت بازیابی کیف پول، کلید خصوصی، فایل پشتیبان محرمانه یا اطلاعات شخصی را در مخزن عمومی بارگذاری نکنید.
3. فایل‌های داخل پوشهٔ استخراج‌شده را به ریشهٔ مخزن بارگذاری کنید، نه اینکه فقط خود ZIP یا یک پوشهٔ تو‌در‌تو را قرار دهید. در ریشه باید `index.html` باشد. می‌توانید از گزینهٔ Upload files در GitHub استفاده کنید و سپس تغییرات را commit کنید.
4. در مخزن به **Settings > Pages** بروید. در بخش Build and deployment، گزینهٔ **Deploy from a branch** را انتخاب کنید، Branch را روی **main** و پوشه را روی **/(root)** بگذارید و **Save** را بزنید.
5. چند دقیقه صبر کنید و همان صفحهٔ Pages را دوباره ببینید تا GitHub نشانی واقعی انتشار را نشان دهد. نشانی پیشنهادی را از روی نام کاربری حدس نزنید؛ نشانی نمایش‌داده‌شده را باز کنید و هر دو صفحهٔ انگلیسی و فارسی، تصاویر، لینک‌ها و موبایل را بررسی کنید.
6. در **Settings > Security** یا تنظیمات حساب، احراز هویت دومرحله‌ای را فعال کنید؛ در Pages گزینهٔ HTTPS را، اگر ارائه شد، فعال نگه دارید. حساب و ایمیل بازیابی را ایمن کنید.

## قالب URL برای پس از انتشار (قالب است، نه نشانی زنده)
- `https://<نام-کاربری-GitHub>.github.io/RWAB-site/`
- `https://<نام-کاربری-GitHub>.github.io/RWAB-site/RWAB-logo-256.png`

این رشته‌ها فقط الگوی جای‌گذاری هستند. آن‌ها را با نشانی واقعی‌ای که GitHub Pages در تنظیمات مخزن نشان می‌دهد عوض کنید. این بسته سایت را آنلاین منتشر نمی‌کند و به GitHub دسترسی ندارد.

## درخواست به‌روزرسانی نشان در PolygonScan
فایل `RWAB-logo-256.png` ضمیمهٔ آمادهٔ ارسال برای درخواست تغییر نشان توکن است. پس از انتشار، می‌توانید URL خام و عمومی تصویر را از دامنهٔ واقعی Pages بردارید؛ قالب آن، نه آدرس واقعی، چنین است:
`https://<نام-کاربری-GitHub>.github.io/RWAB-site/RWAB-logo-256.png`

در PolygonScan صفحهٔ قرارداد توکن ارائه‌شده را باز کنید، دستورالعمل جاریِ به‌روزرسانی اطلاعات/نشان توکن را دنبال کنید و درخواست را از مسیر رسمی ارسال کنید. ممکن است PolygonScan برای اثبات مالکیت یا اختیار، اتصال/امضای کیف پول مالک قرارداد یا مدارک دیگری بخواهد؛ فقط از دامنهٔ رسمی مطمئن شوید، درخواست را خودتان بررسی کنید و **هرگز** کلید خصوصی یا عبارت بازیابی را برای کسی ارسال نکنید. بررسی و پذیرش رایگان یا قطعی تضمین‌شده نیست؛ درخواست ممکن است نیازمند اصلاح، رد یا در صف بررسی بماند. نشان کیف پول‌ها و سرویس‌های مستقل در اختیار ارائه‌دهندگان همان سرویس است و ممکن است متفاوت یا دیرتر به‌روز شود. به‌روزرسانی PolygonScan به معنی تأیید دارایی، پشتوانه یا قیمت نیست.

## امنیت و نگهداری
این سایت JavaScript، کتابخانه یا دارایی بیرونی، فرم، tracker، API یا اتصال کیف پول ندارد؛ پیوندهای PolygonScan با کلیک کاربر به بیرون می‌روند. CSP موجود در meta مرورگر را محدود می‌کند، اما جایگزین CSP در هدر HTTP نیست و امنیت مطلق یا «غیرقابل نفوذ بودن» را تضمین نمی‌کند. قبل از انتشار، فایل‌ها را بازبینی کنید، GitHub و ایمیل را با 2FA ایمن کنید، HTTPS را فعال نگه دارید و هیچ credential یا secret در مخزن عمومی قرار ندهید.

برای به‌روزرسانی سایت، نسخهٔ جدید را با دقت به ریشهٔ مخزن بفرستید، انتشار Pages را بررسی کنید، و اطلاعات زنجیره‌ای را فقط پس از بررسی مستقل تغییر دهید. اعداد فعلی این سایت از اطلاعات ارائه‌شده آمده‌اند؛ سایت آن‌ها را به‌صورت زنده تأیید نمی‌کند.
