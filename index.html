RWAB — document references on Polygon

RWAB is a project for publishing references to document identifiers and hashes through a registry contract on Polygon PoS. A matching hash can help establish whether a copy of a document matches the copy referenced on-chain; it does not validate the document's claims.

1. Project overview

The project publishes a token contract, a separate document registry contract, a website, and public documentation. The registry can store an IPFS identifier and a SHA-256 file hash.

RWAB is not presented as a bank, custodian, fund, or independently audited investment product. Holding the token does not, by itself, establish ownership of the documents' referenced assets or a right to payment, redemption, yield, or profit.
