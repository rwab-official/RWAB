RWAB — a registry for real-world asset metadata on Polygon

RWAB is a technical protocol for registering, tracking and validating real-world asset (RWA) metadata on-chain. Documents are hashed with SHA-256, stored on IPFS, and the hash together with the IPFS identifier is written to a documentation registry contract on Polygon PoS.

1. What this project is

RWAB provides a public, tamper-evident record of documents. Anyone can take a document, hash it, and compare the result against what was written on-chain. If the hash matches, the document is the same one that was registered; if it does not, the document has changed.

  • A token contract on Polygon PoS with a fixed supply of 16,000,000,000 RWAB.
  • A documentation registry contract that stores document hashes and IPFS identifiers.
  • A public repository containing the website, the disclosures and the exact on-chain references.

What this project is not

  • Not a bank, custodian, fund, or investment scheme.
  • The token is not a claim on cash, reserves, collateral or any asset.
  • No yield, return, profit share or redemption right is offered or promised.
  • No audit, valuation or third-party attestation has been obtained.

5. Referenced financial-flow records — project-declared figure

The project declares an aggregate nominal value of EUR 23 billion for the financial flows referenced in the documents it has uploaded and registered.

What this figure is

  • A project-declared aggregate of the nominal values written in those documents.
  • A description of documentary scale — how large the flows described in the uploaded records are.
  • Disclosed openly so that no one has to guess what the project is referring to.

What this figure is not

  • Not cash held by the project, and not a bank balance.
  • Not reserves, not collateral, and not backing for the RWAB token.
  • Not audited, not independently verified, and not confirmed by any third party.
  • Not a market capitalisation, not a token price, and not a redemption value.
  • Not proof of ownership of, or a legal claim to, any of the referenced funds.

Status: project-declared, pending independent verification. The figure is deliberately kept out of the token's on-chain metadata and out of any listing description.
