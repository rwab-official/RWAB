
# RWAB — Real-World Asset Documentation & Evidence Registry

## 1. Project Overview

RWAB is an independently created digital asset documentation and on-chain evidence registry project operating on Polygon PoS.

The project focuses on organizing supporting documentation, preserving digital records, publishing document references, and recording document fingerprints on the blockchain to support transparency and future independent verification.
